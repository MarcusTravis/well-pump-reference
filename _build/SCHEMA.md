# Well Pump Reference Library — data schema and rules

Site: "Well Pump Reference Library". Pages project / default URL: https://wellpumpchart.pages.dev (canonical constant CANON in _build/generate.py).
Repo: MarcusTravis/well-pump-reference. Plain static HTML/CSS/JS, generated by `python3 _build/generate.py`, generated HTML committed. Cloudflare Pages: no build command, output = repo root.

## Data files (one JSON array per category, in _build/)
- submersible.json   — 4-inch (and similar) residential/light-ag submersible pumps (pump ends, pump+motor packages, 2-wire/3-wire)
- jet.json           — jet pumps: shallow-well, deep-well, convertible; also shallow-well/sprinkler-type jet-style residential pumps where sold for wells
- constant-pressure.json — constant-pressure systems (Grundfos SQE / SCALA, Franklin SubDrive / MonoDrive, Goulds Aquavar, Pentair PPC / IntelliDrive, Zoeller, Red Lion, Water Worker etc.)
- tanks.json         — pressure tanks (diaphragm/bladder/air-over-water): Well-X-Trol/Amtrol, Flexcon, Water Worker, WaterWorker, Goulds V-series, Pentair/Sta-Rite, Everbilt, Flotec, Wayne, Zoeller, Red Lion etc.
- controls.json      — pressure switches, control boxes (QD/CR), pump savers / protection, VFDs/constant-pressure controllers sold separately

## Price rule (one rule for every page; say it in each table caption)
"Price = lowest in-stock price for a new unit of that exact model seen on a public US retailer or manufacturer-store listing (seller named and linked), checked on the date shown. No affiliate links."
If you could not see a live price for that exact model, set price_usd null and set price_scale to an editorial band, labelled on the site as "Editorial estimate":
  $ under $250 · $$ $250–$600 · $$$ $600–$1,200 · $$$$ $1,200–$2,500 · $$$$$ over $2,500
Never write a number you did not read on a live page this session.

## Hard rules
- Facts only from official manufacturer pages/catalog PDFs and public retailer listings. Record the source URL.
- Never copy marketing text, photos, pump-curve graphics, or tables verbatim; write short notes in original words.
- Never invent numbers; leave null rather than guess. A missing number is fine.
- Prefer one row per commonly sold model (e.g. 1/2 HP 10 gpm 230 V 2-wire). Aim for broad, realistic coverage of models a homeowner would actually compare.
- Nothing about the site owner's location, employer, or personal life.
